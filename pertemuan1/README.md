# Tugas Kuliah - Pertemuan 1: Program Input dan Struktur KTP

Direktori ini berisi kumpulan program input data kependudukan dan pencetakan struktur KTP yang diimplementasikan dalam 3 bahasa pemrograman berbeda: Python, Pascal, dan C++.

## Struktur Folder

- `python/` : Implementasi menggunakan Python 3 dengan styling ANSI escape codes dan f-string.
- `pascal/` : Implementasi menggunakan Free Pascal dengan escape sequence ASCII `#27` dan directive AnsiString.
- `c++/` : Implementasi menggunakan C++ dengan `std::getline` dan standard library streams.

Dokumentasi teknis lebih detail serta petunjuk cara menjalankan masing-masing program dapat dilihat di file `README.md` pada setiap folder bersangkutan.
